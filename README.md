# Memory Game

Memory Game — браузерная игра на запоминание карточек. 
В игре 16 карточек, которые образуют 8 пар. Цель — найти все пары за минимальное количество ходов.

## Локальный запуск

1. Клонировать репозиторий:
   `git clone <URL_репозитория>`

2. Перейти в папку проекта:
   `cd memory-game`

3. Открыть файл `index.html` в браузере.

## Как играть

- Нажмите на карточку, чтобы открыть её.
- Откройте вторую карточку и попробуйте найти совпадение.
- Совпавшие карточки остаются открытыми.
- Если карточки не совпали, они автоматически закроются.
- Найдите все 8 пар, чтобы завершить игру.
